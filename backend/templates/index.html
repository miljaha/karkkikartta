Using the map
  • Click a pin to see the store's price.
  • Base price stays until someone changes it.
  • Campaign price has a start and end date and replaces the base price while it's active.
  • Prices that need a loyalty card (like K-Plussa, S-Etukortti or Lidl App) are marked as membership prices.
  • Chain-wide campaigns are applied to all stores of the chain, for example, all K-Citymarkets.
  • Prices wrong? Update them in the popup and help others.
  • No irtokarkit in a store? Report it in the popup, and you can undo it the same way.

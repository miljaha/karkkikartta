Website for comparing the price of irtokarkit (loose candy) in stores around Finland and finding the best deals to satisfy sweet cravings.
Prices and sale campaigns can be updated by any users. If you see that the price is wrong or you know there is a deal, let others know :)

The inspiration for this project came from personal interests: hunting the best deals for everything, and my love for irtokarkit 🍫🍬🍭
